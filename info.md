# NSPanel UI Config

Visueller Konfigurator für **nspanel-lovelace-ui** (AppDaemon-Backend) direkt in Home Assistant.
Erzeugt die nspanel-YAML aus einer grafischen Oberfläche und übergibt sie dem bestehenden
AppDaemon-Backend – das Rendering bleibt unverändert.

> Frühe Entwicklungsphase. Siehe README für Status, Roadmap und die einmalige Bind-Mount-Einrichtung
> zwischen HA- und AppDaemon-Container.
